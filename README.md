- Hardware-Aware Machine Learning
- FPGA Acceleration

## Featured Work

### RouteNet Revisited
A from-scratch PyTorch re-implementation and experimental re-examination of RouteNet (ICCAD 2018) for routability prediction.

- Reconstructed the method from the paper alone
- ~3,800 lines of Python
- 235 unit tests
- Experiments across 8 public designs
- Revisited the interpretation of the original ablation study

### Attention Is All You Need — Analysis
A technical study and implementation-oriented analysis of the Transformer architecture, focusing on the reasoning behind self-attention, multi-head attention, positional encoding, and related components.

### Machine Learning for Electrical Engineers
Implementations and experiments exploring machine-learning concepts and their applications to electrical engineering.
